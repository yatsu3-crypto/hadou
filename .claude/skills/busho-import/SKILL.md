# スクリーンショットから武将を追加する

## 大原則
- **画面に写っているものだけを書く。** 推測・記憶・攻略サイトの知識で埋めない。
- 読み取れない、文字がつぶれている、一部が隠れている、2通りに読める → その項目は空欄（数値・文字は `null`、一覧は `[]`）にして `missing` に項目名を書く。
- **追加の前に、変換結果を表で見せてユーザーの確認を取る。** 確認なしに busho.json を書き換えない。
- コミット・push は別途ユーザーの確認を取る。

## 1. 画像の置き方（ユーザー側）
- `~/hadou/screenshots/<武将名>/` に、その武将の画像を何枚でも置く（例：`screenshots/上杉謙信/1.png`、`2.png`）。
- フォルダ分けされずに画像が直下に置かれていたら、どの画像がどの武将かをユーザーに確認する。
- `screenshots/` と `drafts/` は .gitignore 済み（リポジトリには入らない）。画面にプレイヤー名・ID などが写っていても書き写さない。

## 2. 読み取り
1. `ls ~/hadou/screenshots/` でフォルダを確認する（`done/` は処理済みなので除く）。
2. 画像を Read で1枚ずつ見る。画像以外のファイルは開かない。
3. 項目ごとに書き写す：

| 項目 | busho.json | 書き方 |
|---|---|---|
| 武将名・レア度 | `name`・`rarity` | レア度は UR/SSR/SR/R/N |
| 兵科適性 | `aptitude` | 足軽・騎馬・弓・鉄砲・剣豪・忍者の6つ。S/A/B/C |
| 大将時の兵科 | `taisho_heika` | 大将にしたときの部隊の兵科（6種のどれか）。画面で読み取れなければ空欄 |
| 能力値 | `stats`・`power` | 統率・武勇・知略・政治、戦力。画面の数字そのまま（最大値か現在値かを `source` に書く） |
| 天賦 | `tenpu` | 天賦値（数値） |
| 技能 | `skills` | Lv10/20/30/40 の4つ。`name`・`desc`（画面の説明文そのまま）・`tags` |
| 皆伝 | `kaiden` | ランク4〜7。`rank`・`name`・`desc`・`tags`。画面にシーズン表示があれば `season` |
| 戦法 | `senpo` | `name`・`lineage`（系統）・`desc`・`tags` |
| 縁 | `en` | 縁タグの文字をそのまま配列に（例：`["上杉家","平氏"]`） |

4. **効果タグ（`tags`）は説明文から判定する。** 判定なので、確認の表で「判定」と明示する。
   - ダメージ：敵部隊への攻撃・与ダメージ上昇
   - 破壊：城・拠点・施設の耐久へのダメージ
   - 攻城：攻城時に効く効果
   - バフ：味方の能力・速度の上昇
   - デバフ：敵の能力低下、強化効果の打ち消し
   - 回復：兵力の回復
   - 防御：被ダメージ軽減、防御上昇
   - 妨害：敵の行動阻害（足止め・混乱など）
   - 兵科限定の効果なら兵科名（騎馬・弓など）も付ける
   - **意味がわからない用語（例：「金剛」）はタグにせず、確認事項として報告する。**
5. `id` は武将名のローマ字（例：`uesugi_kenshin`）。同じ名前の武将がすでにいたら（別の版など）、id をどうするかユーザーに確認する。
6. `source` は「ゲーム画面のスクリーンショット（画像のファイル名、撮影日がわかれば日付）」、`updated` は今日の日付。

## 3. 下書きと点検
1. `~/hadou/drafts/<id>.json` に下書きを書く。読み取りのメモ（どの画像から読んだか、自信がない理由）は `_note` に書く（追加時に取り除かれる）。
2. 点検する：`node tools/add-busho.js --check drafts/<id>.json`
   - 空欄なのに `missing` に無い項目、語彙にないタグ、形式の誤りはエラーになる。直してから次へ。

## 4. 確認の表（追加前に必ず見せる）
武将ごとに次の形で見せ、ユーザーの確認を取る（AskUserQuestion で「この内容で追加／直す」を聞く）。

```
### 上杉謙信（uesugi_kenshin）UR　出典：screenshots/上杉謙信/1.png〜3.png
| 項目 | 読み取り結果 | 備考 |
|---|---|---|
| 適性 | 足軽S 騎馬S 弓A 鉄砲C 剣豪A 忍者B | |
| 能力 | 統率1088 武勇1100 知略770 政治670／戦力6648 | 最大値 |
| 天賦 | （空欄） | 数字がつぶれて読めない |
| 戦法 | ○○（系統：突撃）タグ：ダメージ・バフ | タグは判定 |
| 技能Lv10 | ○○ タグ：… | |
| … | | |
| 縁 | 上杉家・平氏・軍神・龍・酒豪 | |

空欄・自信がない項目：天賦（読めない）、技能Lv30の説明（一部が隠れている）
確認してほしい判定：「金剛」をどのタグにするか
```

## 5. 追加
1. ユーザーの OK が出たら：`node tools/add-busho.js drafts/<id>.json`（置き換えは `--replace`）
2. `node tests/engine-test.js .` が通ることを確認する。
3. 処理した画像フォルダを `screenshots/done/` に移す。
4. 出力に「実データが10人以上」と出たら、ダミー武将（`dummy: true`）を削除するかユーザーに確認する。
5. CLAUDE.md の「進み具合」に追加した武将を書く。コミット・push はユーザーの確認を取ってから。
